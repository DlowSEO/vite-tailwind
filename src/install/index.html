Install SEO Agent Pro

Bought Pro? These steps take a few minutes. Looking for the free version? Download Lite.

Before you start

Your purchase email from Polar, our reseller, contains your receipt, your licence key and a link to download seo-agent-pro.zip. Download and unzip it, and keep the key handy.

Cannot find the email? Check your spam folder, or contact dan@claudeseo.co.uk.

macOSOptional

Recommended for Mac users: Homebrew

If you are on a Mac and do not already have Python, Git or Claude Code, Homebrew is the simplest way to get them. It is a free package manager that installs and updates tools with one short command each, which is especially handy if you do not use the terminal often.

1. Install Homebrew 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

The installer explains what it will do before it starts. When it finishes, run the commands it shows under "Next steps" so the brew command works in new terminal windows.

2. Install the requirements 

brew install git python
brew install --cask claude-code

Then open Claude Code with claude, sign in, and follow Option 1 or Option 2 below.

Homebrew is a personal recommendation only. SEO Agent has no affiliation with Homebrew, and Homebrew is not needed to use SEO Agent. Current system requirements are listed on brew.sh.

~/option-1 Install on macOS and Linux

RecommendedmacOSLinux

Download seo-agent-pro.zip from your purchase email and unzip it (a Mac does this for you in Downloads). Then run these in your normal terminal (Terminal on a Mac): 

cd ~/Downloads/seo-agent-pro
bash install.sh

The installer copies SEO Agent into Claude Code's folders using bash, which is built into macOS and Linux, so you can delete the download afterwards. It does not need Homebrew. At the end it asks for the licence key from your purchase email; you can also enter it later with /seo setup.

~/option-2 Install on Windows

Windows PowerShell

Download seo-agent-pro.zip from your purchase email, right-click it and choose Extract All. Then run these in PowerShell: 

cd $HOME\Downloads\seo-agent-pro
powershell -ExecutionPolicy Bypass -File install.ps1

Have a look through install.ps1 before running it if you like. At the end it asks for the licence key from your purchase email; you can also enter it later with /seo setup.

~/option-3 Plugin install from the folder

Inside Claude CodemacOSLinuxWindows

Prefer Claude Code's plugin manager? Move the unzipped seo-agent-pro folder somewhere permanent, such as your home folder, then type these into Claude Code, using the folder's full path: 

/plugin marketplace add /Users/yourname/seo-agent-pro
/plugin install seo-agent-pro@dlowseo-seo-agent-pro
/seo setup

Claude Code reads the plugin from that folder, so keep it where it is. /seo setup creates the Python environment and asks for your licence key.

Common fixes

My licence key is not accepted+
Copy the key again from your purchase email, with no spaces at either end. Each key works on up to 3 computers; if you have replaced a computer, email dan@claudeseo.co.uk and the old activation can be cleared.
I cannot find the download link+
It is in your purchase email from Polar, and on your Polar purchase page, which the email links to. Email dan@claudeseo.co.uk if you cannot find either.
/seo is not recognised+
For plugin installs, check /plugin list and reinstall if needed. For manual installs, confirm ~/.claude/skills/seo/SKILL.md exists, restart Claude Code and re-run the installer.
ModuleNotFoundError or other Python errors+
Run /seo setup again. Avoid installing individual packages by hand; SEO Agent uses its own isolated environment.
Python not found on Windows+
Install Python from python.org with "Add to PATH" ticked, then run install.ps1 again. The installer tries py -3, python3 and python in turn.
Audits are slow+
Full audits crawl up to 500 pages with a polite delay between requests, so large sites take a while. Use a Snapshot audit or /seo analyse for quicker checks.

Update or uninstall

Updates are included for all 3.x versions. To update, download the latest zip from your Polar purchase page and run the installer again; your licence stays active. To remove a plugin install: 

/plugin uninstall seo-agent-pro@dlowseo-seo-agent-pro
/plugin marketplace remove DlowSEO/seo-agent-pro

Manual installs: run the uninstaller from the unzipped folder. 

bash seo-agent-pro/uninstall.sh
