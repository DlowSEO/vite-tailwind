Install claude-seo in about two minutes

claude-seo runs locally inside Claude Code. There is no account to create, no subscription and no usage cap beyond your own Claude plan.

Requirements

Tool Why it is needed Check
Claude Code Anthropic's command line tool, installed and signed in claude --version
Python 3.10+ Runs the analysis scripts in an isolated environment python3 --version
Git Used to clone the repository git --version

Chromium is optional. The installer tries to add it for screenshots and JavaScript rendering, and the rest of the toolkit still works if that step fails.

Option 1: plugin install (recommended)

For Claude Code 1.0.33 and later. Run these inside Claude Code: 

/plugin marketplace add DlowSEO/claude-seo
/plugin install claude-seo@dlowseo-claude-seo
/seo setup

Installing the plugin does not run any package managers. /seo setup is a one time step that creates the Python environment and browser in Claude's plugin data folder.

Option 2: macOS and Linux 

git clone --depth 1 https://github.com/DlowSEO/claude-seo.git
bash claude-seo/install.sh

Prefer to read the script before running it? 

curl -fsSL https://raw.githubusercontent.com/DlowSEO/claude-seo/main/install.sh > install.sh
cat install.sh
bash install.sh
rm install.sh

Option 3: Windows (PowerShell) 

git clone --depth 1 https://github.com/DlowSEO/claude-seo.git
powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1

The Windows installer uses a cloned copy rather than piping a remote script, because Claude Code's own safety checks flag that pattern. Have a look through install.ps1 before running it.

Check it worked

  1. 1

    Start Claude Code

    Open a terminal and run claude.

  2. 2

    Run /seo

    Type /seo. You should see the list of commands or a prompt for a URL.

  3. 3

    Run the health check

    Use /seo doctor for plugin installs, or ~/.claude/skills/seo/bin/claude-seo doctor for manual installs.

  4. 4

    Run your first audit

    Try /seo audit https://your-site.com and choose a snapshot or full audit.

Where files are installed

Path Contents
~/.claude/skills/seo/ Main skill
~/.claude/skills/seo-*/ Command skills
~/.claude/agents/seo-*.md Specialist agents
~/.claude/skills/seo/.venv/ Isolated Python environment

Paths apply to manual installs. The installer never installs packages globally or into your user Python.

Common fixes

/seo is not recognised+
For plugin installs, check /plugin list and reinstall if needed. For manual installs, confirm ~/.claude/skills/seo/SKILL.md exists, restart Claude Code and re-run the installer.
ModuleNotFoundError or other Python errors+
Run /seo setup (plugin) or ~/.claude/skills/seo/bin/claude-seo setup (manual). Avoid installing individual packages by hand, the toolkit uses its own isolated environment.
Screenshots fail with an executable error+
Chromium did not install. Run setup again, then doctor, to reinstall the browser into the managed environment.
Python not found on Windows+
Install Python from python.org with "Add to PATH" ticked, then run install.ps1 again. The installer tries py -3, python3 and python in turn.
Audits are slow+
Full audits crawl up to 500 pages with a polite delay between requests, so large sites take a while. Use a snapshot audit or /seo analyse for quicker checks.

Update or uninstall

Plugin installs: 

/plugin uninstall claude-seo@dlowseo-claude-seo
/plugin marketplace remove DlowSEO/claude-seo

Manual installs, using the uninstaller from a fresh clone. To update, uninstall and then install again. 

git clone --depth 1 https://github.com/DlowSEO/claude-seo.git
bash claude-seo/uninstall.sh
