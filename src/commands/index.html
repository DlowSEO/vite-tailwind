Every claude-seo command

Eight commands cover the whole job, from a full audit to strategy and Google data. Depth lives in flags and modes rather than a long menu, so there is less to remember.

All commands

01 /seo audit <url> One command renders your homepage, crawls the site, hands each area to a specialist agent and brings everything back as a scored report with a prioritised list of fixes. Learn more → 02 /seo analyse <url> A focused inspection of a single page covering on-page elements, technical health, structured data, images and performance. Learn more → 03 /seo content <url> Two modes of one job. Learn more → 04 /seo local <url> Everything location based in one command, from Google Business Profile completeness and NAP consistency to reviews, citations and geo-grid rankings. Learn more → 05 /seo geo <url> Generative engine optimisation checks for Google AI Overviews, AI Mode, ChatGPT search and Perplexity. Learn more → 06 /seo backlinks <url> Referring domains, anchor text balance, toxic links and competitor gaps, built on free data sources. Learn more → 07 /seo strategy [mode] Audits look at what exists. Learn more → 08 /seo google [cmd] Crawls tell you what a page looks like. Learn more →

Where to start

  • New to a site? Start with /seo audit for the full picture and a prioritised action plan.
  • Checking one page? Use /seo analyse, with a focus flag if you already know the problem area.
  • Planning growth? Use /seo strategy once the technical basics are in place.
  • Have Google access? Run /seo google setup so audits can use real field and search data.

What changed from the original claude-seo

This build is a simplified fork of claude-seo by Daniel Agrici. Overlapping skills have been merged into single entry points and the long tail of extras removed, while the underlying analysis material is kept inside each merged skill. The extension mechanism is still there, but nothing extra installs by default.
