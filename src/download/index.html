Recommended for Mac users: Homebrew

If you are on a Mac and do not already have Python, Git or Claude Code, Homebrew is the simplest way to get them. It is a free package manager that installs and updates tools with one short command each, which is especially handy if you do not use the terminal often.

1. Install Homebrew 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

The installer explains what it will do before it starts. When it finishes, run the commands it shows under "Next steps" so the brew command works in new terminal windows.

2. Install the requirements 

brew install git python
brew install --cask claude-code

Then open Claude Code with claude, sign in, and follow Option 1 or Option 2 below.

Homebrew is a personal recommendation only. SEO Agent has no affiliation with Homebrew, and Homebrew is not needed to use SEO Agent. Current system requirements are listed on brew.sh.

~/option-1 Plugin install

RecommendedInside Claude CodemacOSLinuxWindows

The quickest route, for Claude Code 1.0.33 and later. Type these into Claude Code itself, not your normal terminal: 

/plugin marketplace add DlowSEO/seo-agent-lite
/plugin install seo-agent-lite@dlowseo-seo-agent-lite
/seo setup

Installing the plugin does not run any package managers. /seo setup is a one time step that creates the Python environment and browser in Claude's plugin data folder.

~/option-2 Manual install on macOS and Linux

macOSLinux

Run these in your normal terminal (Terminal on a Mac): 

git clone --depth 1 https://github.com/DlowSEO/seo-agent-lite.git
bash seo-agent-lite/install.sh

The first line downloads a copy of SEO Agent into a folder called seo-agent-lite. The second runs the installer script inside that folder using bash, which is built into macOS and Linux. Neither line needs Homebrew.

~/option-3 Manual install on Windows

Windows PowerShell

Run these in PowerShell: 

git clone --depth 1 https://github.com/DlowSEO/seo-agent-lite.git
powershell -ExecutionPolicy Bypass -File seo-agent-lite\install.ps1

The Windows installer uses a local copy rather than piping a remote script, because Claude Code's own safety checks flag that pattern. Have a look through install.ps1 before running it.
