White-label questions

Is white-labelling included in Pro?+
Yes. It is part of the £50 one-time price. Lite writes a plain Markdown summary and does not include it.
Do Pro reports show the SEO Agent name?+
No. Pro reports carry no SEO Agent credit line. Once you set your brand, the reports carry only your branding.
Where is my brand information stored?+
On your own computer. SEO Agent does not upload your logo or settings.
Do I need design skills?+
No. You need your logo file and your brand colours as hex codes. Everything else has a sensible default.
Will it change what the audit finds?+
No. Your brand changes how the report looks and sounds. The findings, evidence and scores are the same.
Can I use more than one brand?+
Yes. Keep a brand profile in each client or brand folder and open Claude Code in that folder before you run an audit. SEO Agent uses the profile it finds there, and falls back to your default profile if the folder has none. You set up the folders yourself, and SEO Agent shows which profile it is using before each export.
Can I change my brand later?+
Yes. Update it in settings and every report from then on uses the new version. Reports you have already exported are not changed.
