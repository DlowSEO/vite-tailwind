Findings with evidence

Every issue shows what was found, where, and exactly what to change.

Criticalrobots.txt serves the homepage
GET /robots.txt → 200 · text/html

ImpactSearch engines receive a web page instead of crawl rules, so there is no pointer to the 246-URL sitemap.

FixServe a plain-text robots.txt that references /sitemap.xml.

CriticalNo canonical tags
0 of 40 pages · rel="canonical" missing

ImpactWith www, non-www, http and https versions in play, Google has to guess which URL to rank.

FixAdd a self-referencing canonical to every template.

HighMixed http and https signals
href="http://…/use-of-cookies" · no HSTS header

ImpactLinks and first visits start on insecure URLs, wasting redirects and diluting signals.

FixPoint every internal link at https://www and enable HSTS.

HighOne title shared by 9 pages
"Gallery | Corporate Events…" ×9

ImpactNine gallery pages compete for the same search, so none of them wins it.

FixWrite a unique title and description for each gallery.

Medium28 homepage images with no width or heightCLS risk
