Your SEO team, in the terminal

claude-seo turns Claude Code into a full SEO department: 8 commands trigger parallel specialist agents that crawl your site, diagnose technical, content, and AI-search issues, then hand you a health score and a prioritised action plan: no dashboards, no subscription, just your terminal.

View the repo Install guide

Install 

git clone --depth 1 https://github.com/DlowSEO/claude-seo.git
bash claude-seo/install.sh

Requires Python 3.10+, Git, and Claude Code. The install takes seconds, the audit runs itself, you just read the report.

Commands

/seo audit <url> Full site audit: crawl, parallel specialists, health score, action plan
/seo analyse <url> Page + technical analysis (technical, schema, sitemap, images, hreflang)
/seo content <url> E-E-A-T content analysis, plus content briefs by topic
/seo local <url> Local SEO: GBP, NAP, citations, reviews, geo-grid
/seo geo <url> AI Overviews / ChatGPT / Perplexity readiness
/seo backlinks <url> Backlink profile via free APIs
/seo strategy [mode] Planning: cluster, programmatic, competitor pages, ecommerce
/seo google [cmd] GSC, PageSpeed Insights, CrUX, GA4, Indexing APIs
