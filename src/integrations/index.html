IntegrationsPro

Works with the SEO tools you already pay for

Plug your crawler and your data tools into SEO Agent Pro. Crawl faster, use less of Claude's context and fill your client reports with the data you trust.

Supported tools

Screaming Frog

Built in

Crawling

SEO Agent runs the crawl on your own machine, then reads a compact summary of the results instead of fetching every page.

  • One command starts a headless crawl and exports the data.
  • Counts and example URLs for titles, descriptions, headings, thin content, slow pages, orphan pages and indexability.
  • Cuts the amount Claude has to read on larger sites, so audits finish faster and use less context.

Needs: Your own Screaming Frog installation and licence.

Ahrefs

Official MCP

Backlinks and keywords

Connect Ahrefs through its official MCP server and bring link and keyword data straight into backlink and strategy work.

  • Referring domains, anchors and competitor link gaps.
  • Keyword and ranking data for content and strategy plans.
  • Uses your Ahrefs plan's monthly API units.

Needs: An Ahrefs plan with API access (Lite and above).

Semrush

Official MCP

Backlinks and keywords

Connect Semrush through its remote MCP server for domain, keyword and backlink data alongside your audit.

  • Domain analytics and competitor research.
  • Keyword research and backlink data.
  • Uses the API units on your Semrush plan.

Needs: A Semrush plan that includes API units.

Sitebulb

MCP or export

Crawling

Bring Sitebulb audit data into SEO Agent through Sitebulb's MCP connection or an export, and turn it into a client-ready report.

  • Analyse your Sitebulb exports with the same scoring and action plans.
  • Useful when you already crawl in Sitebulb and want the report written for you.

Needs: Your own Sitebulb licence.

Why connect a crawler

  • Faster audits. A desktop crawler is built to fetch thousands of URLs. SEO Agent reads its results instead of fetching every page itself.
  • Lower token use. Claude reads counts and examples, not raw HTML, so large sites fit comfortably.
  • Data you trust. Findings are based on the same crawl data your team already uses and understands.

How it works

  1. 1

    Install the tool

    Use your existing Screaming Frog, Ahrefs, Semrush or Sitebulb account. SEO Agent does not resell or bundle them.

  2. 2

    Run an audit

    Type /seo audit https://client-site.com. If a supported crawler is installed, SEO Agent offers to use it.

  3. 3

    Get the report

    Findings, scores and the action plan are built from the connected data and delivered as a client-ready PDF.

  4. 4

    Keep control

    Everything runs on your computer with your own accounts and licences.
